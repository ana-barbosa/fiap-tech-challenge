# Audio service - isolated venv (make setup-audio), separate from services/video/'s
# venv so whisperx's own pinned deps don't have to coexist with mediapipe/ultralytics.

# not something services/audio/run.py's transcribe+score pipeline itself needs.

# Pinned to the latest release as of this writing - the isolated venv means whisperx's
# own numpy>=2 requirement no longer conflicts with anything (that conflict only existed

# module docstring for what changed vs. the old 3.1.1 pin (VAD no longer needs a token or
# a manual patch - whisperx now ships its VAD checkpoint as a local package asset;
# DiarizationPipeline's token kwarg is named `token`, not `use_auth_token`).
